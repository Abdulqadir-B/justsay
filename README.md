# JustSay

JustSay helps customer-focused businesses collect short voice reviews and understand customer feedback from a live dashboard.

## Features

- Shareable review links for individual businesses
- Five-second voice review recording
- Automatic transcription
- Sentiment classification and scoring
- Inferred one-to-five star ratings
- Keyword extraction from each review
- Business dashboard with review statistics and recent feedback
- Real-time review updates through Supabase
- Supabase authentication for business owners
- Rate limiting for review processing and business creation

## Tech stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Supabase Database, Auth, Realtime, and Edge Functions
- Google Gemini for transcription and review analysis
- Vercel Analytics and Google Analytics for product monitoring
- Recharts
- lucide-react
